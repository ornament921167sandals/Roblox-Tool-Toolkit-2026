## FAQ

### What exactly is included in the XCutors package?

XCutors is a collection that bundles several well-known executor interfaces (Volt, Synapse Z, Potassium, Wave) alongside a universal loader. The universal loader (xcutorsLoader) is designed to help manage and launch the other executables from a single, convenient interface.

### Is this package safe to use on my computer?

The package is distributed as a clean, compiled application without any embedded malicious code. However, as with any third-party tool modifying game memory, you should always use a secondary Roblox account and understand the potential risks to your primary account.

### How do I update the executors to the latest version?

You should regularly check the GitHub repository's 'Releases' section for new versions of XCutors. Updates that address Roblox patches will be posted there. Simply download the new version and replace your old files.

### Do I need to install all the executors?

No, the universal loader allows you to choose which executor you want to use at any given time. You do not have to run them all simultaneously; you can select and launch only the one you prefer for a specific session.

### What if the executor fails to attach to Roblox?

Common solutions include ensuring you are running the loader as an administrator, temporarily disabling your anticomponent software (which may flag the tool), and checking if the executor has been updated to support the current Roblox version.

### Can I use these tools on Roblox Studio?

XCutors and the included executors are designed for use within live Roblox game clients, not the Roblox Studio development environment. Using them in Studio is not their intended purpose and may cause conflicts.

### Where can I find support if I encounter issues?

You can open an issue on the official GitHub repository's 'Issues' tab. Provide a clear description of the problem, error messages, and steps taken. The community or maintainers may offer guidance there.
